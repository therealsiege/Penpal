### PBLI Integration & AI Chat Functionality

- Team discussed integrating Practice-Based Learning Improvement (PBLI) - one of six core competencies - as key engagement hook for upper-level residents
- Current workflow: residents use browser-native AI chat (e.g., Microsoft Edge's chatbot) to research clinical correlations like bradycardia and dyspnea
- **Critical discovery**: Browser-native AI chat is not HIPAA compliant and not part of eSpiral technology
- Residency manual already prohibits putting patient information into AI tools
- Current AI chat content is not saved/persisted, preventing evaluation of resident PBLI work
- **Major technical need**: Build custom chatbot integrated into eSpiral that can persist interactions and display them alongside patient data

### PHI Security & Compliance Measures

- Browser-based AI chat poses PHI leakage risk even without patient names, as free text box allows any input
- Identified need for MedScrub API to automatically strip PHI from any chat input before sending to AI model
- Plan to install MedScrub on Infirmary infrastructure so PHI never leaves their walls
- MedScrub will tokenize data, allowing AI processing without exposing patient information to large language models
- Residents already anticipated to copy-paste entire chunks of data rather than typing manually, making PHI scrubbing essential
- Copy-paste functionality intentionally disabled in Infirmary's browser environment to prevent PHI leakage
- Dr. Scroggie supports eSpiral specifically because it's outside Epic and not discoverable in legal proceedings - provides "sanctuary space" for resident learning
