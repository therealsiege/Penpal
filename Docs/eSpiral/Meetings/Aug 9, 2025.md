# Aug 9, 2025

[Demo Script](Aug%209,%202025/Demo%20Script.md)

Summary

### Project Status and Development

The meeting focused on development workflow for the eSpiral healthcare project. The participants discussed merging pull requests, branch management, and setting up local development environments. One participant needed to approve a PR and pull down the main branch to create their own working branch. They confirmed that while making improvements was important, there would be no issues with demoing the current version on Monday if changes weren't completed in time.

### UI/UX Considerations

The team discussed the application's visual design, noting differences between the current look and what appeared in the demo video. One participant preferred the cleaner white background that "looks more clinical" and suggested exploring a different logo and color palette that incorporates more green to better convey both the eSpiral brand and healthcare focus. They also discussed an innovative "EMR elements" feature that presents the product in a curated experience, which was described as "next level" and unique.

### Technical Integrations

Several technical components were discussed for the application:

- DeepGram for transcription functionality
- "11 labs" for voice synthesis to avoid having to reproduce changes
- MailChimp integration for capturing email addresses
- Slack for team communications and potential notifications when users request demos
- Security concerns regarding data storage, with specific mention of S3 security

### Domain and Branding

The team discussed domain name acquisition, particularly weighing the benefits of ".io" versus ".ai" domains. They considered purchasing both domains, using ".io" in the short term to avoid potentially "spooking" a client (Infirmary) with AI terminology, while acknowledging that "if we're not using AI, the product's not going to sell."

### AI Implementation Discussion

A significant portion of the meeting involved a philosophical discussion about how AI is changing software development roles. One participant observed that while initially thinking "AI would make us need more developers and less product managers," they now believe the opposite is true. They noted that with AI handling code generation, the bottleneck has shifted to creating well-defined product requirements and domain expertise. They also compared GPT-4 and GPT-5, noting that GPT-5 seems optimized for technical requirements but struggles with product requirements.
