# Dec 23, 2025

Summary

### Overview of eSpiral

- eSpiral is a clinical visualization tool that integrates with Epic EMR to provide a comprehensive, timeline-based view of patient history
- The tool displays 15+ years of patient encounters in a visual format, allowing clinicians to quickly identify patterns and relevant history without scrolling through hundreds of notes
- Current use case focuses on resident education and mentorship, enabling program directors to efficiently review patient charts and provide targeted feedback
- Dr. Clarkson can review all resident admissions across three hospitals (Thomas, Mobile Infirmary, and North Baldwin Infirmary) in approximately 2.5 hours using eSpiral - a process that would take 10 times longer in Epic alone

### Technical Architecture

- eSpiral launches via a SMART on FHIR integration through an FDI (Front Door Integration) record button in Epic's toolbar labeled "guidelines"
- The application opens in a new browser window outside of Epic while maintaining Epic's security protocols
- System leverages FHIR (Fast Healthcare Interoperable Resources) to pull problem lists, encounters, and other clinical data
- Each resident has their own chart instance for each patient, preventing users from interfering with each other's curation work
- The tool includes deduplication algorithms and back-end processing to enable rapid chart curation

### Current Capabilities

- **Timeline Visualization**: Displays encounters chronologically going back 15+ years with ability to expand time periods with single clicks
- **Copy-Paste Filtering**: Can remove duplicate/copied content to show only unique encounters
- **Subspecialty Filtering**: Allows users to filter conditions by internal medicine subspecialty (cardiology, nephrology, gastroenterology, etc.)
- **Icon-Based Interface**: Visual icons matched to ICD codes enable rapid manual curation without reading detailed tooltips
- **Manual Curation**: Currently takes approximately 90 seconds to curate a chart with 200+ conditions by manually selecting relevant items
- **Persistent Views**: Curated views can be saved for 30 days with resident's initials for reference
- **Inpatient and Outpatient**: System works with both hospital and ambulatory encounters

### Proposed Expansion to Residents

- Current access is limited; proposal is to expand to PGY-2 and PGY-3 residents at Thomas Hospital
- PGY-1 residents would not receive access initially
- Faculty members could request access via email
- Access would be optional, not mandatory, for residents
- Residents would need to be briefed and cautioned not to copy-paste eSpiral content back into Epic
- Implementation requires IT to establish a security group to manage user access

### Educational Value and Competitive Advantage

- Tool addresses current gap in evaluating PGY-2 and PGY-3 residents' work, as their clinical reasoning is not readily visible in Epic
- Enables assessment of residents' critical thinking and reasoning skills on a quarterly basis
- Provides "extra layer of oversight" that allows for more comprehensive quality review across all admissions
- Could provide competitive advantage for Thomas Hospital residency program by developing "masters of the American College of Physicians" with superior critical thinking skills
- Enables real-time situational awareness during morning report, allowing attendings to access comprehensive patient history while residents present cases

### Design Partnership Opportunity

- Thomas Hospital is proposed as exclusive design partner for the platform
- Partnership would involve collaborative development based on pain points identified by Dr. Scroggie and others
- eSpiral team is seeking a partner that will support rapid iteration and feature development
- System is described as "market ready" pending feedback from resident usage

### Future Development Plans

- **Automated Filtering**: Future development would enable automatic filtering by ICD-10 codes to eliminate manual curation
- **CDS Hooks**: Clinical Decision Support hooks would enable bidirectional communication, pushing insights and teaching content directly back into Epic at point of care
- **Scalable Mentorship**: CDS hooks would allow program directors to scale their teaching by delivering consistent education to residents without being physically present
- **Resident Scoring**: System could incorporate resident evaluation and certification scoring features
- **Specialty-Specific Applications**: Tool has potential applications in oncology for visualizing chemotherapy interventions over time
- **Future-Dated Planning**: Capability to show future treatment plans and scheduled follow-ups (e.g., 12-month chemo plans, scheduled imaging)
- **Quality Protection**: Information pushed via CDS hooks is not permanently added to clinical record, avoiding quality review concerns

### Potential Broader Applications

- Interest expressed in expanding beyond residency program to attending physicians
- Tool could be valuable for hospitalists and specialists seeing complex patients
- Long-term vision includes marketing to other residency programs and hospital systems once refined
- Recognition that Epic's future progress will likely involve more data visualization rather than additional text
- Hospital administration expressed interest in potential partnership/investment opportunities

### Implementation Requirements

- **User Access Management**: Two proposed strategies discussed :
    1. IT controls button access, only showing to approved users
    2. Button visible to all, but eSpiral validates against approved user list
- Cleanest solution is for IT to create security group for PGY-2 and PGY-3 residents
- IT maintains control of user provisioning and access
- Managing resident access across both sides of the bay (Thomas and other locations) requires IT input since there isn't a common system currently
- Some email correspondence with IT is ongoing regarding configuration details
