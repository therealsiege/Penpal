    Summary
    
    ### Meeting Overview
    
    Clint Johnson demonstrated the eSpiral tool, which integrates with Epic through vendor services. The tool is designed to help physicians curate patient information and create advisories for residents. Matt handles product management and technical requirements for the application.
    
    ### Technical Integration
    
    - eSpiral has moved from OpenEpic to vendor services for better management
    - The app uses Epic's three-legged authentication flow with JWT tokens
    - Features are modular and can be individually enabled/disabled as needed
    - User management flows from Epic's resource-based access control system
    - When launched, the tool automatically receives patient context from Epic
    
    ### Key Features
    
    - **Chart Curation**: Physicians can highlight and organize relevant patient information from the comprehensive medical record
    - **Resident Advisory**: Instructors can create specific guidance notes for residents about patient cases
    - **Workspace Customization**: Users can hide elements and focus on specific aspects of patient history
