# Admin Card Setup (Mockup)

Status: On Development
Assign: Clint Johnson
Details: A card is built from 3 layers:
1. Bottom Layer = Customer photo(s): As Admin, I should be able to define 1+ boxes for Customers to upload photos. As Admin, for each photo upload box, I’ll provide: 
a. size: width x height
b. positioning: (x,y)
c. Z-index: numerical 1-10, with 10 being the top layer… in case photos are intended to overlap (NOT MVP)
d. rotation: # degrees (NOT MVP)

2. Middle Layer = Card Design Mat, which has transparency to allow for customer photos to be seen. It also includes the crop marks for the printer.

3. Top Layer = Customer-Customizable Text: As Admin, I’ll provide parameters for text boxes, including:
a. size: width x height
b. positioning: (x,y)
c. color: #000000
d. font
e. font size (which will probably always be the same as height)
f. Rotation: # degrees (NOT MVP)
g. Z-index (numerical 1-10, with 10 being the top layer, in case multiple text boxes overlap)
