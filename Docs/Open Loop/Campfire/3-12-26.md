### Photon Integration Challenges

- Patient support receiving ~100 tickets daily just for nausea medication resend requests
- Core issue: patients already received medication through Photon but lack visibility, resulting in unnecessary support tickets
- Costing approximately $700 per day in support tickets ($7 per ticket × 100 tickets)
- Photon has two-way texting capability but uses their own Twilio number, creating zero visibility for the team
- Proposed solutions:
    - Give PS team access to Photon for order visibility
    - Have Photon expose communication events to event bus, with team handling outreach through own systems
    - Build Photon order visibility into Clinic App similar to SureScripts integration
    - Add resend functionality through Clinic App API rather than direct Photon access
- Short-term solution: write Photon orders to Healthy medications for visibility (deliverable within a week)
- Long-term solution: create dedicated Photon integration in medication history table alongside SureScripts
- Team hesitant to invest heavily in Photon when full DoseSpot integration could solve same issues

### Complete Cancellation Process

- Significant operational issue: when patients cancel subscriptions, downstream activities continue unnecessarily
- Problems include:
    - Multi-month orders still firing 25+ days after cancellation
    - Async tickets remaining in queue and getting processed
    - Care coaching appointments scheduled for canceled patients
    - Medications sent to billing for already-canceled patients
- Current cancellation process is entirely manual across all clients
- Root cause: disconnected systems without automated downstream cancellation triggers
- Complication: patients can cancel subscription but remain entitled to services through subscription end date
- Key distinction needed: subscription "canceled" vs. subscription "inactive"
- Proposed approach:
    - Set subscription end date correctly when patient cancels (cancel at period end, not immediately)
    - Let payment checker handle invoice-based fulfillment
    - Restrict care coaching and provider visits based on active subscription status
    - Allow order fulfillment for paid invoices regardless of subscription status
- Next steps:
    - Quantify actual impact (how many canceled patients receive unentitled services)
    - Map cancellation workflows for top clients to understand complexity
    - Identify appropriate owner to run audit and develop solution
- Issue also observed: patients being scheduled for sync visits to process cancellations
