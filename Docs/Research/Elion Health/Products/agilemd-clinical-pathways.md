# AgileMD Clinical Pathways

AgileMD Clinical Pathways is an EHR-embedded tool that provides interactive, evidence-based care pathways across inpatient, ambulatory, emergency, ICU, and neonatal workflows. It allows clinicians to view pathway content inside a patient chart, place orders and generate documentation from the pathway, and display real-time labs and vital signs.
