# RiskQual DataTrk

RiskQual DataTrk is a configurable data entry system for healthcare risk, quality, and event reporting. It supports capturing events such as incidents, complaints and compliments, peer reviews, chart audits, medication variances, adverse drug reactions, and patient falls. The platform uses logic-driven forms that adapt based on earlier responses, integrates with master systems for patient, staff, physician, device, and medication data, allows departmentalized access, and supports reporting and analysis of the collected data.
