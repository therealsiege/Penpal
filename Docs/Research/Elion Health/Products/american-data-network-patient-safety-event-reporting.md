# American Data Network Patient Safety Event Reporting

The Patient Safety Event Reporting Application from American Data Network (ADN) is a software tool that helps healthcare facilities report, track, analyze, and act on patient safety events, near misses, and unsafe conditions. It features dynamic and intelligent forms, where fields adjust based on the type of incident, pre-populated patient details provided through admission, discharge, and transfer feeds, automated notifications and task assignments, work queues with reminders, dashboards for interactive analytics, and customizable filters.
