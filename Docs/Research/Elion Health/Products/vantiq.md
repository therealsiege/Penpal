# Vantiq

Vantiq is an event-driven application platform designed for building real-time, distributed applications. It enables users to create solutions that process and respond to real-time data streams from IoT devices, enterprise systems, and other sources. It enables real-time patient monitoring, predictive analytics for ICU capacity, and streamlined emergency response.
