# RXNT AMBIENT IQ

RXNT Ambient IQ is an AI-powered ambient listening tool developed by RXNT to automate clinical documentation. It captures and transcribes provider–patient conversations into structured SOAP notes. The tool integrates with RXNT’s existing EHR and can be used independently via a mobile app for visit recording and note generation.
