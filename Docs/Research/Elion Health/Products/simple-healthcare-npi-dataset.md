# Simple Healthcare NPI Dataset

Simple Healthcare NPI Dataset is a downloadable dataset that aggregates publicly available information from the National Plan and Provider Enumeration System (NPPES). It includes structured data on healthcare providers in the U.S., such as NPI numbers, provider names, specialties, addresses, and taxonomy codes.
