# Adentris

Adentris is an AI-driven clinical documentation quality and compliance monitoring platform that fits into clinical documentation and pre-bill workflows. It connects to hospital EHRs via HL7 and related protocols, monitors workflows continuously, and detects documentation gaps like missed discharge notes or incorrect medication timing.
