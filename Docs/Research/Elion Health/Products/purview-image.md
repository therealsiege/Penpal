# Purview Image

Purview Image is a cloud-based medical imaging platform that allows healthcare organizations to collect, view, store, report on, and securely share DICOM images from any device using a web browser. It includes an FDA-certified, zero-footprint diagnostic viewer for primary image interpretation, along with centralized cloud storage and structured reporting tools.
