# GenHealth.ai for DME

GenHealth.ai for DME is an AI-driven automation platform that handles DME/HME order intake, documentation processing, and medical-necessity checks. It extracts structured data from incoming documents (email, portal, fax), identifies missing requirements, de-duplicates records, and routes documents to the correct workflows. The system applies CMS NCD/LCD criteria, Noridian checklists, or a provider’s own policies to evaluate whether documentation meets eligibility rules.
