# Flow

Flow is an AI-driven revenue cycle and access automation platform that operates in pre-visit access and downstream revenue workflows such as eligibility, prior authorization, coding, claims submission, denials management, and payment posting. It provides AI agents that detect authorization needs and build payer-specific submission packets, performs automated eligibility checks, captures visit documentation via ambient scribing, and supplies intelligent coding and clinical documentation improvement assistance.
