# XCaliber Data Gateway

[Contact](https://www.xcaliberhealth.ai/talk-to-us-form?utm_source=elion&utm_medium=referral&utm_campaign=elion_health&utm_term=contact_sales)

XCaliber’s Interoperability Gateway is a healthcare data integration / connectivity platform that connects to EHRs, labs, imaging systems, and other health IT systems in a variety of protocols and formats (HL7v2, FHIR, C-CDA, JSON, unstructured data). It offers real-time, bi-directional, event-driven and batch data flows, normalization to USCDI / FHIR schemas, terminology mapping, observability & logging, API / GraphQL / REST interfaces, and governance controls like role-based access. It is designed to reduce the engineering overhead of integrations by providing prebuilt connectors, sandbox environments, and controllable pipelines.
