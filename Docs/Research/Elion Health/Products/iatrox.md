# iatroX

iatroX is a clinical reference and learning platform used at the point of care and for professional development. It provides a conversational "Ask iatroX" interface that returns referenced, guideline-anchored answers. It also provides an interactive "Brainstorm" mode to walk through history, examination, differential diagnosis, and management.
