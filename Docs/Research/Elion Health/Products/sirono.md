# Sirono

Sirono is a patient financial engagement platform that consolidates billing information and supports both contact-center staff and patients in managing medical balances. It provides a unified financial view for guarantors and dependents, tools for staff to handle inquiries and process payments, and a self-service portal where patients can review obligations, set up payment plans within hospital rules, and pay via multiple methods.
