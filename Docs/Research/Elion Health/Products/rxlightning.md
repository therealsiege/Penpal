# RxLightning

RxLightning is a prior authorization platform that automates and simplifies the onboarding process for specialty medications. It provides healthcare providers with tools to complete patient enrollment forms, conduct benefit checks, manage prior authorizations, collect consents, and access patient assistance programs.
