# Butterfly Network

Butterfly Network provides the Butterfly iQ family of handheld, whole‑body ultrasound probes and the Compass and Compass AI enterprise software for point‑of‑care ultrasound workflows. The platform provides whole‑body imaging, AI tools that automate lung B‑line counting, and workflow features that capture ambient dictation and support AI‑assisted image review.
