# Google Vertex AI

Vertex AI Platform is a fully managed AI development platform from Google Cloud for building, training, deploying, and operating generative AI and machine learning models at scale. It provides access to Google’s Gemini foundation models, third-party and open models, and tools for agent development, prompt design, model tuning, and evaluation within a single environment.
