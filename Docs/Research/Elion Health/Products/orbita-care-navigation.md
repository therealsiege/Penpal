# Orbita Care Navigation

Orbita Care Navigation is a care-management solution used in pre-visit, intake, procedure-preparation, and post-procedure workflows to support patient adherence and throughput. It provides automated care programs and guided patient journeys that deliver education, collect forms, and sequence preparatory and follow-up tasks.
