# MedAsk Health

MedAsk is an AI-driven symptom assessment tool that allows users to input symptoms conversationally, answer follow-up questions, and receive a list of probable health conditions with explanations, severity insights, and a downloadable report to share with doctors. Built with a focus on medical quality, it is fine-tuned on proprietary medical data and integrated with a comprehensive knowledge base to provide safer, more accurate insights.
