# ZynxOrder

ZynxOrder is a clinical decision support solution used at the point of care to standardize inpatient ordering and support CPOE and EHR order workflows. It provides a maintained library of evidence-based order sets, deploys and customizes those order sets into an organization's EHR using Zynx content management tools, and includes routine evidence updates.
