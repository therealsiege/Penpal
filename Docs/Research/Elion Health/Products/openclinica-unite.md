# OpenClinica Unite

OpenClinica Unite is an eSource solution designed to integrate electronic health record (EHR) data into clinical trial databases automatically. It populates trial case report forms with patient data such as labs, medications, and demographics, reducing manual entry errors and the need for source data verification (SDV).
