# Oracle Clinical Digital Assistant (aka Oracle Health Clinical AI Agent)

Oracle Clinical Digital Assistant is an AI-powered tool that uses voice recognition to capture and input key elements of physician-patient interactions into Oracle Health's EHR system. This assistant facilitates the creation of clinical documentation by generating draft notes for physicians to review and approve.
