# RxUtility

RxUtility is an API-based prescription savings platform that provides real-time access to manufacturer copay coupons within existing healthcare and consumer software workflows. It aggregates and maintains a comprehensive dataset of pharmaceutical copay assistance programs and exposes this data programmatically so partner applications can surface savings at the point of prescribing, pricing, or patient engagement.
