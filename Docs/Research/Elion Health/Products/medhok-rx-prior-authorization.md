# MedHok Rx Prior Authorization

MedHOK provides a cloud‑based Utilization Management and Rx Prior Authorization system, integrated within the broader CareProminence platform. It offers a unified, real-time, role-based interface that enables authorized users to submit and manage pharmacy (and medical) prior authorizations through a provider portal.
