# Mawi Cardiac Monitoring

Mawi Heart provides a wearable cardiac monitoring device designed for remote patient care, featuring continuous beat-to-beat analysis with AI algorithms to detect rhythm abnormalities. The single-use, disposable patch is lightweight, hypoallergenic, and easy for patients to apply at home.
