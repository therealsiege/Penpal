# Flow Auth

[Contact](https://go-flow.ai/request-a-demo)

Flow Auth is an AI-powered prior authorization solution that automates the entire authorization workflow from detecting when one is needed, submitting requests, tracking status, and even drafting appeals. It integrates with EHRs and payer systems, uses payer-specific medical necessity rules to assemble documentation required for each payer, flags missing items, submits through portals/APIs/fax, and delivers status updates within the clinical workflow.
