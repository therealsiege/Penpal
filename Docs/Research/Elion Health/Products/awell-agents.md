# Awell Agents

Contact

Awell Agents is a workflow automation toolkit that enables healthcare product teams to build and run clinical workflows directly within their applications using low-code components and APIs. It allows developers to define workflows—such as care plans, follow-ups, or intake processes—in a visual builder and embed logic-driven actions (e.g., sending messages, updating records) into their existing systems.
