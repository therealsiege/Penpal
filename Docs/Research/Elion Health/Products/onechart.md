# OneChart

OneChart is an AI-powered clinical documentation platform designed to support healthcare providers across specialties like primary care, behavioral health, home care, and sports medicine. The tool automates charting, billing code suggestions, and clinical form filling, integrating directly with existing EHRs via lightweight connections.
