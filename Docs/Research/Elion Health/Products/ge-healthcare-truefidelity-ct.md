# GE Healthcare TrueFidelity CT

GE HealthCare TrueFidelity CT is a deep learning–based CT image reconstruction software that improves image sharpness and reduces noise while preserving clinically meaningful detail. It reconstructs CT images from raw data using a neural network trained on low-noise reference images, supporting faster interpretation and reduced reader fatigue for radiologists.
