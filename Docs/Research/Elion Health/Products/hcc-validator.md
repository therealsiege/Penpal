# HCC Validator

HCC Validator is a tool used during clinical documentation and claims review to validate Hierarchical Condition Category (HCC) diagnoses for MEAT compliance and RADV audit readiness. It provides concurrent checks during provider documentation and retrospective reviews of submitted diagnosis codes and flags MEAT deficiencies and high-risk codes.
