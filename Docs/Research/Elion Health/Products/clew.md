# CLEW

CLEW provides AI-driven predictive analytics for healthcare, particularly in ICUs and other critical care environments. The platform aggregates data from EHRs and patient monitoring systems, to create real-time physiological profiles of patients. CLEW’s system continuously monitors these profiles using AI models to predict patient deterioration, sending alerts to care teams when necessary.
