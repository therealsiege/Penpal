# Denniston Data Healthcare Pricing Guide

The Denniston Data Healthcare Pricing Guide (HPG) provides a comprehensive tool for accessing U.S. medical benchmark prices using data from Transparency in Coverage and Medicare. It allows users to view negotiated prices from various healthcare payers for all services and providers.
