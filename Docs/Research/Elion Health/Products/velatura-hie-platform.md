# Velatura HIE Platform

The Velatura HIE Platform is a health information exchange infrastructure that facilitates the secure sharing of clinical data among healthcare organizations, public health entities, and community partners. It supports interoperability through standards-based data exchange (e.g., HL7, FHIR, Direct Secure Messaging) and provides services such as master patient index management, consent tracking, and real-time event notifications.
