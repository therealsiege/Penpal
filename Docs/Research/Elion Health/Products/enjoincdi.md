# EnjoinCDI

Contact

EnjoinCDI is a clinical documentation integrity (CDI) program designed to improve documentation accuracy, optimize coding, and support value-based care. Unlike technology-driven CDI solutions, Enjoin takes a physician-led, education-focused approach with tailored programs, frequent record reviews, and peer-to-peer physician education.
