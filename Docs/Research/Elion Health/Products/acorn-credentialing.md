# Acorn Credentialing

Acorn Credentialing offers a comprehensive platform designed to automate and streamline the medical credentialing and payer enrollment processes. Key features include credentialing as a service, blockchain for secure data sharing, data migration from legacy systems, virtual medical staff management, and a mobile scanner for easy document uploads.
