# Kivo Health

Kivo Health provides a virtual pulmonary rehabilitation program for patients with chronic respiratory diseases, particularly COPD. The program includes live, supervised sessions led by licensed respiratory therapists and pulmonologists, remote monitoring using pulse oximeters, and a mailed kit that includes a cellular-connected tablet.
