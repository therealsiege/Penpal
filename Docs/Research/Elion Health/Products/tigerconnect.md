# TigerConnect

TigerConnect is a clinical communication and collaboration platform used in hospital and health system workflows for real-time team communication, alarm management, and interoperability-driven workflow automation for patient flow and care coordination. It provides secure messaging (text, voice, video), delivery and read confirmations, secure attachments, and administrative controls for user provisioning and authentication.
