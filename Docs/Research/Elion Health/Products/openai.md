# OpenAI for Healthcare

OpenAI for Healthcare includes ChatGPT for Healthcare (a secure, HIPAA-oriented workspace) and the OpenAI API for Healthcare, which can embed GPT-5.2 into clinical and operational systems for workflows like point-of-care support and discharge.
