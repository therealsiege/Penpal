# iCALIBRATE

iCALIBRATE is a managed care contract intelligence platform that helps healthcare providers monitor, validate, and negotiate payer contracts in real time. It creates detailed rate sheets based on contract terms, indexes these to Medicare rates, and identifies discrepancies between expected and actual reimbursements using 835 payment files.
