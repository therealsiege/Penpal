# IMO Core Periop

IMO Core Periop is a surgical scheduling solution to enhance operating room (OR) efficiency and accuracy. It standardizes surgical procedure terminology and maintains up-to-date mappings to CPT and HCPCS codes within the electronic health record (EHR) system.
