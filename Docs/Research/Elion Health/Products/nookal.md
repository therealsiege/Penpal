# Nookal

Nookal is a cloud-based practice management software designed for allied health professionals. It provides tools for appointment scheduling, patient records, billing, and reporting. Features include customizable clinical notes, automated reminders, online bookings, and integration with Medicare and Xero for claims and accounting.
