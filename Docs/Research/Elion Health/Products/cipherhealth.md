# CipherHealth

CipherHealth provides software for patient engagement across three core areas: automated outreach, structured rounding, and patient-initiated feedback. CipherOutreach supports multichannel communication by voice, SMS, and web for use cases such as pre-visit instructions, post-discharge follow-up, and closing care gaps. CipherRounds standardizes patient, staff, and location rounding with configurable scripts and issue routing. Self Service enables patients to submit feedback from their own devices via QR code or text without a login.
