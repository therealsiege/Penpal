# TransformativeMed Core Work Manager

TransformativeMed's Core Work Manager is a clinical workflow tool designed to enhance inpatient care by integrating with electronic health records (EHRs). It provides specialty-specific worklists and automates tasks such as rounding, patient handoffs, and discharge planning.
