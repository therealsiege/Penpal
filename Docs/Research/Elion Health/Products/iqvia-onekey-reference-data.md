# IQVIA OneKey Reference Data

IQVIA OneKey Reference Data is a global healthcare provider reference database used to support commercial, clinical, and compliance operations. It offers detailed, continuously updated information on healthcare professionals (HCPs) and healthcare organizations (HCOs), including identifiers, affiliations, specialties, and contact data.
