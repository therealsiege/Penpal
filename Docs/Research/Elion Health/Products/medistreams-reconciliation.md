# Medistreams Reconciliation

MediStreams Reconciliation is a payment reconciliation solution that matches electronic funds transfers (EFTs) with electronic remittance advices (ERAs) to create fully funded 835 posting files for healthcare providers. The system automates the matching process using data from NACHA or EDI 820 files and compares it against 835 files based on configurable criteria
