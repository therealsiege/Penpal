# GeBBS iCodeOne

GeBBS iCodeOne is a cloud-based health information management (HIM) platform that consolidates medical coding, auditing, compliance, and risk adjustment into a single AI-driven system. It supports professional, outpatient, and inpatient coding across multiple specialties, using large language models and rules-based validation to provide real-time coding feedback, documentation queries, and error prevention before claims submission.
