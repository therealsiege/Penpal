# Oystehr

Oystehr offers a hosted headless EHR platform for healthcare developers, including FHIR API support, cloud infrastructure, compliance, identity management, messaging, telemed, eRx, real-time eligibility and claim submission as a single service, enabling both HIPAA and ONC compliance for healthcare applications.
