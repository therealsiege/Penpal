# Symplr Directory

symplr Directory is a centralized provider-data management platform that allows health systems and payers to maintain a “single source of truth” for all provider profiles. It collects, validates and aggregates provider data across credentialing, privileging, enrollment, network management, referral search and digital front-door directories.
