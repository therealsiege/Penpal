# TheraPulse

TheraPulse is an AI-powered assistant designed for mental health professionals to automate session documentation. It offers features such as live session transcription, automated progress notes in customizable formats (e.g., DAP, SOAP, BIRP), and detailed session summaries to provide actionable insights.
