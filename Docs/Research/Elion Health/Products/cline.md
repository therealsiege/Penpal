# Cline

Cline is a programmable electronic health record (EHR) platform that allows clinicians to build and deploy custom apps, agents, dashboards, and patient-facing websites using natural language prompts. It combines core EHR functionality with a flexible interface that lets providers design workflows such as follow-ups, billing agents, specialty-specific views, and analytics without traditional software development.
