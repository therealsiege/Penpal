# VitalChat

VitalChat is a virtual nursing and remote monitoring platform built for hospitals. It provides remote nursing support through audio and video combined with ambient sensors, and it uses artificial intelligence to detect risks such as falls, bed exits, and distress signals. The system integrates with the electronic health record, supports centralized command center operations, enables multi-room monitoring, and delivers real-time alerts to improve response times.
