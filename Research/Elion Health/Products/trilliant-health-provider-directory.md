# Trilliant Health Provider Directory

Trilliant Health's Provider Directory delivers accurate, near real-time insights into the behavior and affiliations of over 2.9 million healthcare providers across the United States. The directory leverages advanced machine learning and a robust all-payer claims dataset to correct outdated information, and offers detailed data on provider practice locations, patient panels, referral patterns, and financial relationships.
