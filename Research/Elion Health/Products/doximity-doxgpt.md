# Doximity Dox GPT

Doximity GPT is a HIPAA-compliant AI assistant designed for clinicians that supports clinical reference lookup, documentation generation, and administrative tasks within medical workflows. The tool provides evidence-based answers to clinical questions using a structured knowledge graph derived from peer-reviewed guidelines, journals, and drug databases, enhanced through the integration of Pathway’s clinical reference dataset.
