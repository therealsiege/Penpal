# AWS Bedrock

AWS Bedrock is a managed platform for building, deploying, and operating generative AI applications and agents using multiple large language models through a single API. It provides access to foundation models from different providers, tools to customize models with private data, orchestration for AI agents, and built-in controls for security, monitoring, and governance.
