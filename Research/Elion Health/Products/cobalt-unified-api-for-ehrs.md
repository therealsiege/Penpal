# Cobalt Unified API for EHRs

Cobalt Unified API for EHRs offers a single REST-based interface to integrate with multiple electronic health record (EHR) systems, simplifying access to and manipulation of clinical and administrative data. It supports endpoints for patients, appointments, notes, documents, orders, claims, locations, insurance, tasks and more. It also provides webhooks for real-time updates and handles authentication via client credentials and user access tokens.
