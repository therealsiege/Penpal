# Microsoft Azure AI

Azure AI is an enterprise AI platform from Microsoft that provides tools and infrastructure to build, deploy, and govern AI applications and agents at scale. It includes access to large language models, agent orchestration, AI development services, AI-optimized databases, and security and governance capabilities integrated across the Azure cloud.
