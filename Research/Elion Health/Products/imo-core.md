# IMO Core

IMO Core is a clinical documentation and terminology solution that embeds into EHR workflows to improve diagnosis specificity, problem list management, and downstream financial performance. It provides clinicians with structured, clinician-friendly diagnosis search and comprehensive medical terminologies mapped to major coding systems, while surfacing real-time prompts for documentation gaps, coding errors, and missed HCCs.
