# MaxMD

MaxMD is an interoperability suite used in clinical and administrative workflows to exchange clinical data among providers, payers, and patients. It provides Direct secure messaging, supports query APIs for consumer-directed record retrieval, and provides an event-notification engine with lightweight dashboards that surface transitions-of-care and alerts.
