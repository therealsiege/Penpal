# Epic Willow

Epic Willow is a pharmacy management module built into the Epic Systems Corporation platform that supports medication-use workflows across inpatient, ambulatory and inventory settings. It allows ordering, dispensing, administering, inventory tracking, and integration with other Epic modules so that medication-related processes are captured within the same EHR environment.
