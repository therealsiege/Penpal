# CDE One

CDE One is an AI-powered clinical documentation platform that ingests structured and unstructured EHR data to identify potential documentation gaps. It generates prioritized worklists, surfaces in-line query suggestions, and embeds code references and clinical evidence directly into the EHR interface.
