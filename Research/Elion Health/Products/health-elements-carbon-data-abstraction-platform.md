# Carbon Data Abstraction Platform

Carbon Data Abstraction Platform is an AI-based system that automates clinical data abstraction for quality reporting, research, and clinical registries. Using large language models, the platform extracts and structures data from unstructured clinical documentation in electronic health records, supporting workflows such as case finding, data abstraction, validation, analytics, and direct submission to national registries. It surfaces relevant chart evidence for each data element and allows optional human review to confirm recommendations.
