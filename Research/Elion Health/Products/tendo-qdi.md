# Tendo QDI

Tendo QDI (Quality Documentation Improvement) is a workflow management application that supports clinical documentation improvement teams by identifying, prioritizing, and managing documentation review opportunities. It uses data analysis to surface high-value charts and at-risk cases, then organizes this work into task dashboards that guide reviewers through chart review, coding clarification, and provider query generation.
