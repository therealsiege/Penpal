# Managing Google Fonts

Status: On Development
Requirement: As an Admin User, I need a way to maintain a list of all the Google Fonts that might be used to customize cards. 

Two options: 
Option 1: dropdown list of all fonts available on Google Fonts, and the Admin checks a box for which ones to include. 

Option 2:  can be free text (with verification or validation) or links to the fonts on fonts.google.com.

This list of fonts that the Admin selects then becomes the drop-down list in the Card Setup UI for potential fonts to be used in textboxes.
Release: 1.0
