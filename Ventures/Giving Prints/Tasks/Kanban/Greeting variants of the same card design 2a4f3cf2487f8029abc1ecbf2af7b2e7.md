# Greeting variants of the same card design

Status: Not started
Requirement: The same card design can have multiple greetings, for example, “Happy Holidays” and “Merry Christmas”. To setup, it requires a different Design Mat for each greeting. As an Admin in the Card Editor UI, I need to be able to upload multiple Design Mats, add a label for each (that is customer-facing). 

As a Customer, I need to be able to choose between the greetings in Card Personalization UI.
