# Remove the ability for customers to edit the font on customizable text

Status: On Development
Requirement: As a Customer customizing a card, I should not have the ability to edit the font family on customizable text. 

For some text boxes on the back, I may be allowed to modify the font size. To enable this:
1. As Admin in the Card Setup UI, for textboxes on the Card Back, add a setting to “allow customer to edit font size”

2. As Customer in the Card Customization UI, if allowed by the Admin, add the ability to change font size and style (bold, italic, underline).  
Release: 1.0
