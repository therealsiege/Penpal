# As Customer, when selecting a card from the gallery to customize, I receive an error 404: Card not found. (Issue not previously resolved)

Status: Needs Changes
Requirement: We previous attempted to resolve this issue unsuccessfully. 

What it is doing (and shouldn’t be): As a Customer on index.html, when I select a card thumbnail from the gallery to customize, I receive an error 404. When I acknowledge the issue, it takes me to a blank card.

What it should be doing:
1. Each gallery thumbnail corresponds to a specific Card Template that the Admin created in the Card Management UI.
2. The application should take me to that specific card to customize with my own photo, text, etc.
