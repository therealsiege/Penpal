# [ARCHIVED] Healthie EMR — Current State (Mar 2026)

<aside>
📋 Healthie is the current EMR powering much of OpenLoop's clinical network. API-first EHR platform with a GraphQL-based API, built on Ruby/Postgres/React/React Native.

</aside>

## Core Capabilities Used by OpenLoop

- Patient management & charting
- Scheduling & appointments (+ Google/Outlook sync)
- Forms & intake
- Chat/messaging
- Lab orders & results
- E-prescribe (DoseSpot integration)
- Billing & insurance (claims, payments, CMS-1500)
- Documents & notes
- Metrics & care plans
- White-label settings
- Webhooks
- Food/nutrition tracking

## Developer Tools

- GraphQL Schema Explorer
- React SDKs (Chat, Forms)
- MCP dev-assist tool (healthie/healthie-dev-assist on GitHub)

## API Model

Closed API available on Enterprise/Group plans. Sandbox environment available for development. Backwards-compatible versioning policy.
